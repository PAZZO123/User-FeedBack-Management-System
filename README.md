# User Feedback Management System

A Java application where users log in, send feedback and see the results, with a client-server chat.

## Features

- Login page
- Feedback form and results page
- Client and server chat windows

## Built with

Java, Swing and Maven (`pom.xml`).

## How to run

Open the project in NetBeans (or another Java IDE) and run the main class. The `.form` files are NetBeans GUI designer files for the Swing windows.
